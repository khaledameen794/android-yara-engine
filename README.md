# android-yara-engine

بنية بناء صغيرة ومستقلة لإنتاج **YARA-X C API** لأندرويد. النطاق الأول **arm64-v8a** وAndroid API 24 أو أحدث، وليس تطبيق Android أو غلاف JNI أو حزمة قواعد كشف.

## المدخلات المثبتة

YARA-X `v1.21.0` عند commit `7b2637d4655155fdfaf68177edadb9a39406ece0`، وRust `1.97.1`، وNDK r30 `30.0.16248370`. تحفظ `pins.json` روابط المصدر وNDK وبصمات SHA-256 وCargo.lock، وتستخدم عملية البناء `--locked`. الرقعة الصغيرة تعطل ميزات المحرك الافتراضية وتبقي `constant-folding` و`exact-atoms` و`fast-regexp`؛ لا تُفعّل وحدات التحليل الافتراضية.

يُثبّت كل Action بمعرّف commit كامل. لا push أو PR أو schedule يشغّل البناء تلقائيًا؛ workflow يعمل يدويًا من `main` فقط، والنشر اختيار منفصل افتراضيه معطل. صلاحية البناء قراءة فقط، وصلاحية كتابة محتويات المستودع محصورة في job نشر الأصول. لا يحتاج رمزًا شخصيًا أو GitHub Packages؛ يستخدم النشر رمز الوظيفة المؤقت فقط.

## البناء على Linux x86_64

يلزم Python 3.12+ وRustup وGit/patch وبيئة Linux. تنزيل NDK واستخدامه يخضعان لشروط Android SDK المنشورة. يمكن تعيين `ANDROID_NDK_HOME` إلى تثبيت محلي بنفس الإصدار؛ CI ينزل الأرشيف المثبت ويُحقق SHA-256. لا يُوزع NDK نفسه.

```bash
rustup toolchain install 1.97.1 --profile minimal --target aarch64-linux-android --no-self-update
python3 scripts/bootstrap.py
bash scripts/build.sh
python3 scripts/notices.py
python3 scripts/verify.py
```

تكون المخرجات داخل `dist/`: `libyara_x_capi.so` و`yara_x.h` و`metadata.json` و`SHA256SUMS` وإشعارات التراخيص. SONAME هو `libyara_x_capi.so`، ومحاذاة مقاطع ELF مقدارها 16 KiB. يعيد البناء تعيين مسارات المصدر والكاش إلى أسماء عامة، ولا يُضمّن مسارات الجهاز في بيانات الإصدار. يُوقَف البناء قبل نقص المساحة أو inodes عن الحدود المحددة؛ لا يحذف كاشًا خارجيًا.

لمحاولة بناء أخرى بعد تطبيق الرقعة، شغّل `bootstrap.py` مجددًا لإعادة تحضير نسخة مصدر نظيفة. قابلية إعادة البناء هنا تعني المدخلات والخيارات المثبتة والتحقق من الناتج؛ لا يُدّعى تطابق ثنائي مستقل بايتًا ببايت ما لم يُقارن بالفعل.

## Releases والتحقق

شغّل workflow **Build Android ARM64 C API** يدويًا. يتيح `publish=false` التحقق والاحتفاظ بملفات workflow المؤقتة فقط. اختيار `publish=true` ينشر GitHub Release جديدًا بعد نجاح البناء والتحقق. يرفض الناشر إعادة استخدام وسم أو إصدار قائم، ولا يستبدل أصولًا سبق نشرها. الأصول ليست GitHub Packages، ويمكن تنزيل المكتبة والـheader وملف البصمات مباشرة من Releases.

```bash
sha256sum -c SHA256SUMS
```

يجب تنزيل ملفات الإصدار كافة إلى المجلد نفسه لتشغيل أمر التحقق الكامل. يسجل metadata إصدار المصدر والأدوات والـABI والخيارات، ويتحقق السكربت من ELF64/AArch64 وSONAME والتبعيات والرموز العامة والمحاذاة والبصمات. **هذا يثبت بناءً عابرًا والتحقق البنيوي، وليس تشغيلًا على جهاز Android أو صلاحية محلل APK أو تغطية كشف أمني.** يلزم اختبار الاندماج والوقت والذاكرة والإلغاء في التطبيق المستهلك.

## التراخيص

ترخيص MIT في الجذر للبنية الجديدة فقط. YARA-X وتبعياته يحتفظون بتراخيصهم؛ تتضمن أصول الإصدار نص BSD الأصلي وإشعارات تبعيات Rust. عندما لا يرفق ناشر crate نصًا منفصلًا، تُحفظ بيانات الترخيص المنشورة ولا يُخترع إشعار حقوق. حالة `ascii_tree 0.1.1` موضحة داخل الإشعارات: إعلان MIT وبيانات الناشر الأصلية محفوظان مع شروط MIT، إذ لا يتاح نص أصلي منفصل أو مستودع الناشر حاليًا. لا تُفهم هذه الملاحظات على أنها مراجعة قانونية مستقلة.

المراجع الأصلية: [YARA-X C API](https://virustotal.github.io/yara-x/docs/api/c/c-/)، [تنزيلات NDK الرسمية](https://developer.android.com/ndk/downloads)، و[تأمين GitHub Actions](https://docs.github.com/en/actions/reference/security/secure-use).
